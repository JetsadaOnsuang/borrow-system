# IT Inventory — ระบบยืม-คืนอุปกรณ์ไอที

เว็บแอปภาษาไทยสำหรับดูคลังอุปกรณ์ บันทึกการยืม ตรวจสอบสต็อก และรับคืนอุปกรณ์ ออกแบบให้เผยแพร่เป็น static site บน GitHub Pages ได้

## เริ่มใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือเปิด GitHub Pages จาก repository ที่มีไฟล์ชุดนี้ ข้อมูลตัวอย่างและธุรกรรมจะบันทึกใน LocalStorage ของเบราว์เซอร์/อุปกรณ์ที่เปิดเว็บนั้น

หน้าล็อกอินเดโมใช้บัญชี `User` และรหัสผ่าน `User1234` ชื่อบัญชีจะถูกผูกเป็นชื่อผู้ยืม และกดออกจากระบบเพื่อล้างสถานะล็อกอินของแท็บปัจจุบัน

**ข้อจำกัดด้านความปลอดภัย:** ระบบล็อกอินนี้เป็นเพียงตัวอย่าง UI ฝั่ง browser เท่านั้น รหัสผ่านที่ฝังใน JavaScript ตรวจดูได้จาก source ของเว็บ และข้อมูลใน LocalStorage แก้ไขได้โดยผู้ใช้ จึงห้ามใช้รหัสผ่านจริงหรือพึ่งพาการล็อกอินนี้เพื่อปกป้องข้อมูล/สิทธิ์การใช้งาน หากต้องการ auth จริง ต้องใช้ backend ที่ตรวจสอบ credentials และกำหนดสิทธิ์ฝั่ง server

## API สำหรับการยืม

`app.js` เปิดฟังก์ชัน `window.ITInventory.borrowEquipment({ borrower, equipmentId, quantity, dueDate })` สำหรับการยืม โดยค้นหาอุปกรณ์ ตรวจว่า `quantity` เป็นจำนวนเต็มบวก และเปรียบเทียบกับจำนวนคงเหลือ (`จำนวนทั้งหมด - รายการยืมที่ยังไม่คืน`) ก่อนบันทึก หากสต็อกไม่พอจะปฏิเสธรายการและแจ้งจำนวนที่เหลือ

ฟังก์ชันนี้เป็น API ฝั่ง browser สำหรับเดโม ไม่ใช่ HTTP server API: LocalStorage ไม่มีการทำธุรกรรม/ล็อกข้ามอุปกรณ์ จึงไม่เหมาะกับการใช้งานหลายผู้ใช้จริงพร้อมกัน หากต้องการข้อมูลกลางและป้องกันการยืมแข่งกัน ให้นำ `schema.sql` ไปใช้กับ backend และตรวจสต็อกพร้อมสร้างรายการยืมใน database transaction เดียวกัน

## Schema

`schema.sql` กำหนดตาราง `equipment`, `borrowers` และ `loans` พร้อม foreign keys, ข้อจำกัดจำนวน และ indexes สำหรับค้นหารายการยืมที่ยังไม่คืน

## Security check ที่ทำ

ทดสอบ Stored/DOM XSS ด้วยชื่ออุปกรณ์ลักษณะ `<img src=x onerror=alert(1)>` และชื่อผู้ยืมที่มี HTML: ข้อมูลผู้ใช้ถูกแสดงผ่าน `textContent` และ `createElement` ไม่ถูกนำไปประกอบเป็น HTML จึงแสดงเป็นข้อความและไม่รัน event handler การทดสอบนี้ตรวจในเบราว์เซอร์ได้โดยเพิ่มอุปกรณ์ด้วย payload ดังกล่าว

## เผยแพร่บน GitHub Pages

1. อัปโหลดไฟล์ `index.html`, `app.js`, `styles.css` และ `schema.sql` ขึ้น repository
2. เปิด **Settings → Pages**
3. เลือก branch ที่ใช้งานและโฟลเดอร์ `/ (root)` แล้วกดบันทึก
4. รอ workflow เผยแพร่เสร็จ แล้วเปิด URL ที่ GitHub Pages แสดงให้
